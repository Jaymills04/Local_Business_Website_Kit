# Local Business Website Kit

A collection of **modern, high-converting one-page website templates** for local businesses in Indianapolis and beyond.

Built with **Tailwind CSS + Alpine.js** — fast, responsive, and easy to customize.

### Included Templates
- Gym / Fitness
- Restaurant / Cafe
- Home Contractor
- Real Estate Agent
- Dental / Medical Clinic
- Auto Repair Shop

### Features
- Fully responsive design
- Fast loading (Tailwind CDN)
- SEO-friendly structure
- Easy color theming
- Contact forms + booking modals
- Ready for Vercel / GitHub Pages

### How to Use
1. Pick a template folder
2. Customize text, colors, and images
3. Deploy in minutes
